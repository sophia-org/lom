# Completed work

Completed task lines live in monthly todo.txt-format files named
`done-YYYY-MM.md` beside `todo.md`. The CLI writes directly to the current month;
this page stays a short guide. Each line retains its stable task ID, completion
date, and link to detailed evidence.

Use `zk completed` to list monthly files. The [tracking contract](docs/work-tracking.md)
defines completion and evidence requirements.
